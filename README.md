# Adaptive room equalizer on the STM32H755 (Nucleo-H755ZI-Q)

This project focuses on the implementation of adaptive equalizers for room correction on a Nucleo-H755ZI-Q. Two approaches were implemented. Both were tested with two analog MEMS microphones (SPH8878LR5H), a PCM1808 ADC as the audio input input and a PCM5102A DAC as output.

# Filterbank_adaptive_EQ  

This method focuses on the adaptive correction with IIR filters. Only the magnitude of the room transfer function (RTF) is corrected. 

This approach is partly based on the following literature.

-A. Leite and A. J. S. Ferreira, "An improved adaptive room equalization in the frequency domain," in *Proc. 118th Audio Engineering Society Convention*, Barcelona, Spain, May 2005.

-S. Cecchi, L. Romoli, P. Peretti, and F. Piazza, "An adaptive multiple position room response equalizer," in *Proc. 19th European Signal Processing Conference (EUSIPCO)*, Barcelona, Spain, 2011, pp. 1274–1278.

# Unbiased_MIMO_EQ

This approach is an attempt to correct the RTF using FIR filters. In the current state the convergence speed is slow (2-7min) and the frequency response is corrected above 800-900Hz 

The literature that it was based on are:

L. Fuster, M. de Diego, M. Ferrer, A. Gonzalez, and G. Piñero, "A biased multichannel adaptive algorithm for room equalization," in *Proc. 20th European Signal Processing Conference (EUSIPCO)*, Bucharest, Romania, 2012, pp. 1344–1348.

A. Farina, "Simultaneous measurement of impulse response and distortion with a swept-sine technique," in *Proc. 108th Audio Engineering Society Convention*, Paris, France, Feb. 2000, Paper 5093.

# Tools

Both approaches include 2 scripts to generate the correction files:

-`REW_to_EQ.py` converts the REW measurements into a inverse filter file in the "REW" format.

-`EQ_to_BIQUAD.py` converts the output either from `REW_to_EQ.py` or from the EQ Tool of REW to the correction files for both projects.

The names of the input files need to be changed in the scripts.
